Lokra locks rows for AI agents. It sits between your agents and Postgres, and lets the database itself decide what each one can see and change.

There is nothing new to learn. Agents connect over MCP like any other tool. Each one gets its own database role, identifiers are masked before the agent sees them, writes wait for a person to approve, and every action lands in a signed log.

It can stop an agent from reading another clinic's patients, cancelling the wrong appointment, or pasting a Medicare number into a chat. It works with Claude Code, Cursor and any MCP client, and it is open source.
