Lock rows for AI agents.

An MCP server that sits between your agents and Postgres. The database decides what each agent can read and change, identifiers are masked, and every write waits for a human.

// how it works

01

Database-enforced

Each agent logs in as its own Postgres role. Grants and row-level security decide access, not a SQL parser.

02

Masked by default

Medicare and IHI numbers, emails and phone numbers are hidden before the agent sees them, even inside free text.

03

Humans approve writes

Every INSERT, UPDATE and DELETE is dry-run, shows how many rows it would touch, and waits for a person.

04

Signed audit ledger

A hash-chained log of every request: which agent, on whose behalf, and what happened.
